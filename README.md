# House Price Prediction Using Machine Learning

## Project Overview
This project uses machine learning to predict house prices based on factors such as area, number of bedrooms, bathrooms, and parking spaces.
The project was built using Python in Google Colab.

## Tools & Libraries Used
- Python
- pandas
- scikit-learn
- matplotlib

## Machine Learning Model
- Linear Regression

## Project Workflow
1. Loaded and explored the dataset
2. Selected important features
3. Split the dataset into training and testing sets
4. Trained a Linear Regression model
5. Made predictions on house prices
6. Evaluated model performance using Mean Absolute Error

## Key Learning Outcomes
- Introduction to machine learning
- Data preprocessing
- Model training and prediction
- Model evaluation
